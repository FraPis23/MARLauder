MARLauder — Architecture (the released M=4 configuration)

GPU-resident multi-agent exploration · MAPPO with a CTDE critic · 6-layer ego-centric GAT encoder · a genuinely learned policy (no analytic target, no guidepost) steered by graph features + a per-direction value field V_k + five rendezvous scalars + a pathfront belief of the teammate feeding feat[4]/feat[6].
This page describes only what is actually active in the released configuration (source: pipelines/train_full.sh, stage 4). What exists in the code but is switched off is collected in the last section.

Principles: (1) a learned policy, not a planned one — no analytic target and no guidepost; the network steers from graph features (local utility feat[2] + beyond-window radar feat[5]/[6]), from five rendezvous scalars, and from the value field V_k (as input and as a logit bias, NEVER as an imposed target); (2) one shared encoder, two heads (decentralized actor / centralized count-invariant CTDE critic); (3) act() (rollout, sampling) ≟ evaluate_step_from_enc() (update, replay) — the same computation in two regimes; (4) one change per experiment, and every flag that alters semantics is passed explicitly so params.json records it.
